# Native conversational dependency links, 2026-10-13 09:00

## Phase 1: hypotheses and locked acceptance

H55a: current native neighborhoods disappear after reply assembly. The source graph
has no durable record of which peer setup or reply relationship was observed. This
prevents auditing and invalidating a future abstraction when its setup changes.
Baseline: authenticated bounded live context is ephemeral; automatic native pattern
studies remain gated by H54a. Mechanism: link the verified source to bounded,
content-free dependency fingerprints in the existing private graph, under the shared
source lock. So that later contextual learning can track its actual evidence rather
than treating an isolated remark as a personality pattern. This is enabling work,
not a claim of measured character or humor improvement.

Acceptance fixed before implementation: real collector-to-handler path stores a
source-linked capture after restart, at most five attributed human dependencies,
source timestamps and reply relations, gap metadata, extraction version and capture
time. No peer text, captions, OCR, interpretations or bot/development evidence is
persisted. Source edits, peer edits/deletes, in-flight invalidations, retention,
withdrawal and restored stale captures fail closed and remove graph backups.
The capture is an observed neighborhood, never proof of complete context or current
visibility. Automatic native pattern gate stays closed in all layers. Missing graph
and denied reads keep normal replies available. Bounded existing Discord reads and
zero additional provider requests; existing USD18/2/20 ledger and participation.
Validate with unchanged-baseline and candidate synthetic lifecycle/handler cases,
all six engineering gates, immutable release, installed hashes and actual private
owner Discord requests plus a disposable development-only handler fixture.
Disconfirm if raw peer content persists, stale metadata survives a known mutation,
intake expands, normal replies fail, or a capture opens the pattern gate.

H55b: context-aware native studies could improve humor/stance interpretation. Still
unvalidated. Requires fresh per-dependency visibility checks immediately before both
provider passes and commit, bounded complete study packets, contrary cases, genuine
human held-outs and actual natural responses. This capture increment is insufficient.
H48 qualified abstract population remains exploratory with zero active patterns.
H22/H39 brevity/novelty remain same-model behavioral experiments. H46 selective
skills/tools and generated U.P. aurora/trail-camera scenes remain exploratory and
require original-pixel/sharing/timing evidence and generated provenance.

## Phase 2: roadmap decision

Split H54b/H50 into H55a bounded durable dependency capture, then H55b fresh dependency
verification and contextual study eligibility. Select H55a now: the absence is
confirmed in code and a useful prerequisite can ship without an unvalidated behavioral
assumption. Confidence high for the engineering boundary; fidelity impact unresolved.
Existing app graph, learning lock and invalidation markers are dependencies; no new
schema/service/model/ledger or source replay. Metadata cap and retention make storage
bounded. Stronger human abstractions or a tested full dependency lifecycle can reorder
population. Next H55b + H48; then brevity/variation/cues, broader native/visual coverage,
selective skills/tools and generated scenes. Keep six standalone runs and current
model/reasoning/notification settings.
